- 🌍 **Current Weather:** Get up-to-date temperature, humidity, and wind details for any city.  
- 🕒 **Forecast:** View 5-day weather predictions with clear visual icons.  
- 📍 **Location-Based Search:** Automatically detect your current location or search by city name.  
- 🎨 **Responsive Design:** Works seamlessly across desktop and mobile devices.
